# Booking-System

This is a Java-based Booking System application.

## Features
- User registration and login
- User profile management
- Hotel and Hotel Room management
- Booking and Payment processing
- Feedback system
- Secure password handling

## Technologies
- Java 17
- Maven
- SQL Server (via JDBC)

## Structure
- `src/main/java/com/mycompany/Softwarepr1/models`: Data entities (Booking, Feedback, Hotel, HotelRoom, Payment, User)
- `src/main/java/com/mycompany/Softwarepr1/ui`: User interface components
- `src/main/java/com/mycompany/Softwarepr1/util`: Utility classes (Database, Password management)
